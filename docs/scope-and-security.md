## 공개 저장소 범위

이 저장소는 팀 프로젝트에서 직접 구현·수정한 기능을 정리한 개인 기여 코드 발췌입니다. 팀 전체 소스에 대한 본인 기여를 주장하지 않습니다.

일부 공통 UI·타입 정의와 앱 진입점이 포함되지 않아 전체 앱을 독립 실행하는 구성은 아닙니다. `package.json`과 [환경변수 예시](../.env.example)는 사용한 패키지 및 설정 이름을 확인하기 위한 자료입니다. 설치와 환경변수 설정만으로 전체 서비스가 실행되지는 않습니다.

## 로그인과 권한 통제

Context API와 `useReducer`로 로그인 상태를 관리하고, 프로토타입용 사용자 식별 토큰을 `localStorage`에 저장합니다. 재접속 시 사용자 ID와 만료 정보를 확인해 상태를 복원합니다.

- 실제 JWT 서명 검증이나 Firebase Authentication을 사용하는 구조가 아닙니다.
- 비밀번호 처리는 클라이언트의 SHA-256 해시 기반이며 운영용 인증 시스템으로 설명하지 않습니다.
- Firestore Security Rules 구현은 본 저장소의 개인 기여 범위가 아닙니다. 현재 운영 환경의 규칙 상태를 이 저장소만으로 확인할 수 없습니다.
- 화면의 로그인 여부·소유자 확인은 서버 측 권한 통제를 대체하지 않습니다.

## 결제·거래

Firestore에 결제 상태를 저장하고 `held`, `completed`, `refunded`, `released` 등의 변경 흐름을 처리합니다. 에스크로 거래 흐름을 표현한 프로토타입이며 실제 PG 결제 승인, 자금 보관·정산 또는 실제 에스크로 서비스를 구현한 것은 아닙니다.

구매 생성 함수는 물품 존재 여부와 `available`을 검사한 뒤 구매 문서를 바로 `completed`로 저장하고, 물품의 `available`을 `false`로 갱신합니다. 이 상태는 실제 결제 승인이나 대여 종료를 확인한 결과가 아닙니다.

구매 상태 변경 함수는 완료 시 물품을 대여 불가로, 취소 시 대여 가능으로 변경한 뒤 구매 상태를 갱신합니다. 각 문서는 순차적으로 처리하며, Firestore 트랜잭션이나 Atomic Batch Write에 따른 원자성·동시 요청의 중복 거래 방지를 보장하지 않습니다.

## 리뷰 작성 조건과 화면 표시

- 예약 ID가 없는 일반 구매 리뷰는 `itemId + buyerId + status: completed` 조건으로 완료 구매를 조회하며, 이력이 없거나 조회에 실패하면 작성을 거부합니다.
- 예약 ID가 있는 분기는 물품·예약 존재 여부를 확인하지만, 예약 완료 상태를 검사해 작성을 차단하는 로직은 없습니다.
- 구매 내역의 `hasReview`와 후기 작성 버튼 표시는 기존 리뷰 조회 결과에 따른 UI 처리입니다. 리뷰 생성 함수의 중복 작성 검사를 구현한 것은 아닙니다.
- 리뷰의 `purchaseId`는 완료 구매 조회 결과의 첫 문서에서 얻습니다. 선택한 구매 ID를 후기 모달에서 전달받아 정확히 그 거래에 연결하는 구현으로 설명하지 않습니다.

## 이미지 등록과 실패 시 상태

물품 문서를 `images: []`로 먼저 생성하고, 생성된 `itemId`로 이미지 저장 경로를 구성합니다. 전체 업로드·URL 조회가 성공하면 URL 배열로 물품 문서를 갱신합니다.

- 업로드·URL 조회 실패 시 문서 갱신으로 진행하지 않지만, 이미 생성한 물품 문서는 남습니다.
- `Promise.all()` 실패는 다른 업로드를 취소하지 않으며, 성공한 파일의 자동 삭제·문서 삭제·자동 재시도는 없습니다.
- 업로드 이후 문서 갱신 실패도 같은 이미지 업로드 실패 메시지로 전달하므로 두 실패 원인을 별도로 구분하지 않습니다.
- 물품 ID·시각·난수를 조합한 파일명은 충돌 가능성을 줄이는 방식이며, 충돌의 완전한 방지나 업로드 성능 개선 수치를 주장하지 않습니다.

## 기능 범위

| 영역 | 실제 구현 | 포함하지 않는 기능 |
|---|---|---|
| 채팅 UI 갱신 | `onSnapshot` 결과 반영 | Optimistic Update |
| 메시지 읽음 처리 | 개별 `updateDoc()`을 `Promise.all()`로 처리 | `writeBatch()` 기반 Atomic Batch Write |
| 조회 정렬 | 일부 쿼리의 서버 `orderBy` 제거 후 클라이언트 정렬 | 복합 인덱스 정의·최적화 |
| 이미지 | 파일별 크기·MIME Type 검사, 물품 ID 기반 병렬 업로드·전체 URL 수집 | 자동 리사이징·압축·롤백·재시도 |
| 지도 | 장소 검색·마커·지도 클릭·역지오코딩·위치 선택 | 거리 기반 검색·위치 기반 추천 |
| 상태 관리 | Context API·Custom Hooks | TanStack React Query 기반 구현 |

위 한계는 기존 프로토타입의 범위이며, 이번 문서 정리에서 새 기능을 추가하거나 인증·결제를 개선하지 않았습니다.
